# Exclusion Pick-and-Place

200개 IK 시연으로 학습한 π₀.₅-DROID LoRA 두 모델의 최종 체크포인트를 비교합니다. 시드 1000–1019를 두 모델에 동일하게 사용합니다. 시드별 정사각형 큐브 배치는 위치와 수평 회전이 무작위화됩니다.

두 모델은 동일한 전체 지시문을 받습니다. Subtask 모델은 각 요청에서 단계 문장을 직접 생성하며 영상에 해당 문장을 표시합니다. 정책은 15 Hz DROID 속도 명령을 내고 16개 중 처음 4개를 실행합니다. 평가 시간은 시뮬레이션 기준 최대 120초이며, 성공 판정 후 1초 유지가 필요합니다.
